# Kimi Claw — краткая памятка для Windows

## Новая сессия

```powershell
cd "C:\claw cod"
& ".\claw-code-parity — копия (2)\claw-kimi.cmd"
```

## Продолжить сохранённую сессию

Запустите Kimi обычной командой выше, затем внутри Claw:

```text
/resume session-1788445447090-4504-0
```

Посмотреть доступные сессии:

```text
/session list
```

Одно неинтерактивное продолжение из PowerShell:

```powershell
& ".\claw-code-parity — копия (2)\claw-kimi.cmd" `
  --resume session-1788445447090-4504-0 prompt "продолжай"
```

## Режимы работы

Обычное обсуждение; Kimi сама решает, нужны ли инструменты:

```text
/agent off
```

Обязательное реальное действие для текущего пользовательского turn:

```text
/agent on
```

После первого реального tool result Kimi снова может завершить turn обычным
текстом. Проверить текущий режим:

```text
/agent status
```

По умолчанию новая сессия запускается с `/agent off`.

## Полезные команды

```text
/status                  состояние сессии
/models                  список моделей
/permissions             текущие права
/compact                 сжать длинную историю
/help                    все команды
Esc                      остановить текущий turn
/exit                    сохранить сессию и выйти
```

## Важно

`claw-kimi.cmd` сейчас запускает Claw с `danger-full-access`. `/agent off`
отключает обязательный вызов инструмента, но не уменьшает права. Для просмотра
Upwork/Freelancer явно пишите: не кликать, не вводить данные и не отправлять
заявки.

Windows-команды выполняйте через `PowerShell`. Инструмент `Bash` в Kimi-сессии
направлен в WSL `Ubuntu-24.04`.
